Flood options

These curves contain no state or county key. Selecting a zone filters by Hazus flood-zone type, not a geographic location.

Hazus records a zone only for the curves it assigns by default. The rest of the library is alternates selected manually in Hazus, with no zone published anywhere — so choosing a zone narrows results to the zone-flagged subset. Leave this on All to search the full library.

Hurricane options

Region / flood zone is not applicable to hurricane curves. These curves contain no state or county key.
